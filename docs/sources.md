# 来源接口

影像清单见 /index。许可范围和遮挡均用半开矩形 [左,上,右,下]，以原幅左上像素角为原点。pixelAxes 表示测绘坐标的 x 轴是否与原始像素相反。共视点与控制对中的像素坐标已按测绘轴方向记载，原幅定位区间需以原始像素给出。
/survey 的 controls 提供像素与实地方向正交的坐标标定对应，ties 提供两幅图中同一实地点的像素对应和测量误差。共视对只在两幅同层图且状态有效期间使用。各站测量遵循相同的有限精度，误差由 errorMm 声明。同一位置的两条可行路径在实地坐标相差超过请求的 toleranceMm 时需复核。
原幅为 PGM P5 灰度数据。资源在公布的目录变动后可能过期，单次演练回放刻度内成功下载的总限额见 /index。超过限额返回 429，作废原幅 410。
